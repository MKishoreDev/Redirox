About Redirox

Redirox is a minimal open-source URL shortener built with Flask and MongoDB. It supports password-protected links, expiration dates, QR code generation, and easy sharing while keeping the experience clean and lightweight.

Key Capabilities

  • Create short, memorable links instantly
  • Secure links with password protection
  • Set precise expiration dates and times
  • Generate scannable QR codes
  • Easy sharing on social platforms

How It Works

  1. Paste your long URL in the input field
  2. Optionally add a password for security
  3. Set an expiration date and time if needed
  4. Click "Shorten Link" to generate
  5. Share via copy, QR code, or social media

Use Cases

  • Social media marketing and engagement
  • Email campaigns and newsletters
  • Secure sensitive document links
  • Time-limited promotional links
  • Mobile-first QR code sharing
